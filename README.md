# VICE PROTOCOL: NEON COAST

An open-world 3D GTA-inspired action-driving game built with **Three.js, TypeScript, React, and Procedural Web Audio** — zero external assets required.

## The Objective: The $100,000 Grand Heist Protocol
The Crimson Syndicate double-crossed you and locked a **$100,000 Golden Vault Core** inside **Fort Bayview** on Causeway Island. Tear across **4 distinct coastal districts** (Neon Strip, Ocean Drive, Harbor Docks, Causeway Island), complete **4 escalating Heist Protocol Quests**, upgrade your gear on the Black Market, hack the city grid mid-chase, survive a **5-Star helicopter lockdown**, and launch off the **Ocean Pier Mega-Ramp** onto your Getaway Yacht!

### Core Features
- **4 Handcrafted Story Quests**:
  1. *Fast Cash: Neon Run* — Intercept & wreck 3 Crimson Syndicate Courier SUVs downtown (`+$15,000` + Turbo Nitro Mk-II).
  2. *Blackout: Relay Sabotage* — Destroy 3 guarded Signal Relay Towers across Ocean Drive & Neon Strip (`+$20,000` + Net-Hack Upgrade).
  3. *Apex Machine: Hypercar Heist* — Steal the Prototype Apex-X from Palm Royale Valet, outrun a 3★ chase, and repaint at Harbor Neon Pay-n-Spray (`+$25,000` + Apex-X Unlocked).
  4. *The Grand Heist: Bayview Vault* — Storm Causeway Island, crack the Vault Convoy, survive a 5★ NCPD Interceptor & Helicopter Spotlight chase, and jump Ocean Pier onto the Getaway Yacht (`+$40,000` + King of Neon Coast!).
- **Open-World Sandbox Activities**: 3 Instant Street Races (green gates), 6 Glowing Stunt Mega-Ramps with slow-mo aerial camera, 8 Collectible Synth Cassettes, Drive-Through Neon Pay-n-Spray Garage, Destructible Props (exploding barrels, water-geyser fire hydrants, streetlamps, beach umbrellas), and Random Armored Cash Van events.
- **In-Game GTA Smartphone (`Tab`)**: Heist Ops, City Net-Hack (Traffic Chaos, EMP Shockwave Dome, Scanner Spoof), Black Market Upgrades, Instant Vehicle Garage, and 3-Station Procedural Synthwave Car Radio.

## Run Locally
```bash
npm install
npm run dev
```
Open `http://localhost:5175`.

## Controls
| Key | Action |
| :--- | :--- |
| `W A S D` / Arrows | Drive / Walk |
| `Space` | Handbrake Drift (Car) / Jump (On Foot) |
| `Shift` | Nitro Boost (Car) / Sprint (On Foot) |
| `E` | Hijack / Exit Any Vehicle |
| `Q` / Left-Click | Auto-Lock Plasma Blaster (On Foot & Drive-By!) |
| `1` / `2` / `3` | Net-Hack: Traffic Chaos / EMP Dome / Spoof -1★ |
| `C` | Cycle Camera (GTA 6 Chase ↔ Classic Top-Down ↔ Hood) |
| `R` | Cycle Procedural Radio Stations (WAVE 88.5 / PALM 101.2 / PULSE 99.9) |
| `Tab` | Open In-Game Smartphone |
| `M` | Full Interactive City GPS Map |
| `P` | Toggle Director / Demo Sandbox Toolbar |
| `F` | Reset / Unstuck Car to Nearest Road |
| `H` | Honk Horn |
